# ChatGPT用 キャラクターデザイン依頼書（メディアブレイン営業ポータル）

このファイルをそのままChatGPTに貼り付けて、キャラクターとサムネイルを作ってもらうための資料です。
できあがった画像は、ポータルの **「画像一括取込」**（http://localhost:4322/import-art）にまとめてドラッグ＆ドロップすると、自動で各ワールドに反映されます。

---

## 0. 先に読んでください（著作権・安全面）

- 作るのは **オリジナルのキャラクター** です。既存作品（鬼滅の刃・ブルーロック・進撃の巨人・ビックリマン など）のキャラクター、ロゴ、名称、構図の模倣は **依頼しないでください**。
- 「◯◯風」と作品名で頼むと、ChatGPTが断ったり、似すぎた画像が出たりします。**作品名は使わず、見た目の特徴で指定**します（各ワールドの「画風の指定」にそのまま使える文章を用意しました）。
- 画像は商用利用を前提に、**ご自身で利用できるもの**だけを取り込んでください。

## 1. ChatGPTへの最初の指示（これを最初に貼る）

```
あなたはキャラクターデザイナーです。
これから「営業チームのAI社員」のオリジナルキャラクターを、世界観ごとに6人ずつデザインしてください。
・既存作品のキャラクター、ロゴ、固有名詞は使わず、完全オリジナルにしてください。
・同じ世界観の6人は、同じ画風・同じ色味で統一してください（人物ごとに髪型・目・体型・小物で個性を出す）。
・顔がはっきり見える、胸から上のバストアップ。背景はシンプル（世界観の色のグラデーション程度）。
・文字やロゴは画像に入れないでください（名前や数字を入れる指定があるものだけ除く）。
・正方形（1:1）、1024×1024px、PNGで出力してください。
まず世界観を1つ伝えます。6人を1人ずつ出力してください。
```

## 2. 画像の仕様

| 種類 | サイズ | 作り方のコツ |
|---|---|---|
| キャラ画像（1人1枚） | 1024×1024px（正方形）、PNG | 顔を中央〜やや上に。画面では**丸く切り抜いて表示**されるので、顔と肩が真ん中に収まる構図にする |
| サムネイル（ワールドごとに1枚） | 1600×1000px（横長 16:10）、PNG/JPEG | 主役は**右寄り**に。左側と下側は暗め・余白多めにする（ワールド名やボタンの文字が重なるため） |

- 1枚5MB以下（キャラは3MB以下）。形式は PNG / JPEG / WebP / GIF。
- 同じワールドの6人は **同じチャットの中で続けて作る** と画風がそろいます。

## 3. ファイル名のルール（これで自動で振り分けられます）

```
{ワールドID}_{役割ID}.png        例）oa_scout.png
{ワールドID}_thumb.png            例）oa_thumb.png
```

**ワールドID**

| ワールド | ID |
|---|---|
| 代理店開拓（開拓団） | `agency` |
| スポーツ（ブルーアリーナ） | `sports` |
| OA・トナー・フック商材（市松ムダ退治隊） | `oa` |
| Web制作・広告・DX支援（キラキラ・シール王国） | `web` |
| 飲食（のれん街道） | `food` |
| 精肉・とことん871（とことんアリーナ） | `meat` |

**役割ID（6役は全ワールド共通。役割は変えません）**

| 役割ID | 役割 | 担当 |
|---|---|---|
| `scout` | 営業・候補発掘 | 有望な候補を探す |
| `analyzer` | 調査・分析 | 実在・連絡先・根拠を確認 |
| `planner` | 提案・戦略 | 提案の角度を設計 |
| `writer` | 営業文作成 | メール・LINE・電話メモを書く |
| `manager` | 進行管理 | フォロー予定と進行を管理 |
| `reviewer` | 最終確認 | 送る前の最終チェック（人の承認の前） |

## 5. 取り込み手順

1. ChatGPTで作った画像を、上のファイル名にして1つのフォルダにまとめる（一部だけでも可）。
2. ポータルの **「画像一括取込」** を開く → 画像をまとめて選択 → 「取り込む」。
3. キャラ画像は、そのワールドの該当する役の見た目として反映されます（名前・必殺技などは今のまま。変更は「キャラクター」タブから）。サムネイルはトップのポスターとワールドのヘッダーに反映されます。
4. 気に入らない画像は、同じファイル名で取り込み直すと上書きできます。「設定」タブの「標準のイラストに戻す」で元に戻せます。

## 6. うまく作るコツ

- 1ワールドごとに新しいチャットを開き、最初に「1. 最初の指示」→「画風の指定」→1人目、の順で依頼する。
- 1人目の画像が気に入ったら「同じ画風・同じ色味で、次は◯◯（2人目の人物像）」と続ける。
- 顔が切れる／斜めになりすぎる場合は「正面向き、胸から上、顔を画像の中央上寄りに」と追加で指示する。
- 画像に文字が入ってしまったら「文字を入れずに作り直して」と伝える（背番号など、指定したもの以外）。
